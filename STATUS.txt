📦 BACKEND API READY FOR USE

    Authentication
    ├─ POST   /api/auth/token/            (get JWT token)
    ├─ POST   /api/auth/refresh/          (refresh token)
    └─ GET    /api/auth/me/               (current user profile)

    Incident Management
    ├─ GET    /api/incidents/             (list with filters)
    ├─ POST   /api/incidents/             (create new incident)
    ├─ GET    /api/incidents/{id}/        (detail view)
    ├─ PATCH  /api/incidents/{id}/        (update status)
    └─ POST   /api/incidents/{id}/action/ (workflow transitions)

    Alerts & Notifications
    ├─ GET    /api/alerts/                (critical alerts)
    ├─ GET    /api/notifications/        (user notifications)
    └─ POST   /api/notifications/{id}/read/ (mark as read)

    System
    └─ GET    /api/health/                (health check)
